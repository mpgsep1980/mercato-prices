Comment récupérer mon token ?
⚠️ Fais cette manipulation depuis un ORDINATEUR, pas un téléphone : sur mobile, se connecter à mpg.football ouvre souvent directement l'appli, et la page web n'existe alors plus pour aller y chercher quoi que ce soit.

1. Sur l'ordinateur, va sur mpg.football et connecte-toi normalement (comme d'habitude).
2. Une fois connecté, appuie sur la touche F12 du clavier. Un panneau s'ouvre (les "outils de développement") — ne t'inquiète pas, on ne va rien casser.
3. En haut de ce panneau, clique sur l'onglet "Console" (s'il n'est pas déjà affiché).
4. Clique dans la zone de texte de cette console, colle le code ci-dessous, puis appuie sur Entrée — il copie directement ton token dans le presse-papier, pas besoin de le sélectionner à la main.
(function(){var f=false;for(var i=0;i<localStorage.length;i++){var k=localStorage.key(i);if(k&&k.indexOf('@@auth0spajs@@')===0){try{var v=JSON.parse(localStorage.getItem(k));var tok=v&&v.body&&v.body.access_token;if(tok){f=true;(function(token){if(navigator.clipboard&&navigator.clipboard.writeText){navigator.clipboard.writeText(token).then(function(){console.log('%cToken copie dans le presse-papier ! Colle-le (Ctrl+V) directement dans le champ de l\'appli.','color:#2f9e44;font-weight:bold;font-size:14px')}).catch(function(){console.log('Copie automatique impossible, copie ce texte a la main :');console.log(token)})}else{console.log('Copie automatique indisponible, copie ce texte a la main :');console.log(token)}})(tok)}}catch(e){}}}if(!f)console.log('Token introuvable. Es-tu connecte sur mpg.football ?');})();
5. Si un message bleu/jaune s'affiche du genre "Ne collez pas de code que vous ne comprenez pas" et refuse le collage : tape le mot qu'il indique (souvent "allow pasting" ou "autoriser le collage"), appuie sur Entrée, puis recolle le code de l'étape 4.
6. Un message vert "Token copié dans le presse-papier !" apparaît — si à la place le token s'affiche en texte brut (certains navigateurs bloquent la copie automatique), sélectionne-le et copie-le à la main (Ctrl+C).
7. Ferme les outils de développement (F12 à nouveau), colle (Ctrl+V) dans le champ plus bas sur cette page, puis clique "Enregistrer".

Si tu n'as qu'un téléphone sous la main : essaie d'ouvrir mpg.football en navigation privée avant de te connecter (ça empêche parfois le basculement automatique vers l'appli), ou repère un lien "Continuer dans le navigateur" si le site en propose un.
Astuce : menu du navigateur → "Ajouter à l'écran d'accueil" pour l'ouvrir comme une appli.
